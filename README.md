# Makecode-Base64Utils

A simple utility script for Microsoft MakeCode!

This script provides an easy way to encode and decode Base64 strings using the UTF-8 character set. It includes functions for both encoding regular text into Base64 and decoding Base64 back into readable text.

The main purpose of this project is to make working with Base64 in Microsoft MakeCode easier and more convenient, without having to write your own encoding and decoding functions from scratch.

Unlike implementations that only support basic ASCII characters, this script uses UTF-8, allowing it to properly handle a wider range of characters, including special characters and non-English text.

**Features:**
- Encode regular text into Base64.
- Decode Base64 strings back into regular text.
- UTF-8 character set support.
- Simple functions that can easily be integrated into other MakeCode projects.
- No need to implement your own Base64 encoding or decoding logic.

Whether you're working with text, handling encoded data, or just need a simple way to work with Base64 in your MakeCode projects, this utility aims to make the process a little easier!
